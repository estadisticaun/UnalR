# Índice del paquete

## Tablas

- [`Tabla()`](https://estadisticaun.github.io/UnalR/reference/Tabla.md)
  :

  Cree fácilmente un widget para visualización de tablas HTML usando el
  paquete `DT`

- [`Tabla.General()`](https://estadisticaun.github.io/UnalR/reference/Tabla.General.md)
  **\[obsoleta\]** :

  Cree fácilmente un widget para visualización de tablas HTML usando el
  paquete `DT`

- [`Tabla.SaberPro()`](https://estadisticaun.github.io/UnalR/reference/Tabla.SaberPro.md)
  **\[obsoleta\]** :

  Cree fácilmente un widget para visualizar los resultados de la prueba
  Saber Pro en tablas HTML usando el paquete `DT`

## Gráficos

- [`Plot.Apiladas()`](https://estadisticaun.github.io/UnalR/reference/Plot.Apiladas.md)
  : Cree un gráfico de barras apiladas dinámico/estático y flexible

- [`Plot.Barras()`](https://estadisticaun.github.io/UnalR/reference/Plot.Barras.md)
  : Cree un gráfico de barras que muestre la información de forma
  horizontal o vertical, para variables nominales u ordinales con dos
  diferentes paquetes

- [`Plot.Boxplot()`](https://estadisticaun.github.io/UnalR/reference/Plot.Boxplot.md)
  : Cree un diagrama de caja/boxplot dinámico y flexible con dos
  diferentes paquetes

- [`Plot.Drilldown()`](https://estadisticaun.github.io/UnalR/reference/Plot.Drilldown.md)
  :

  Cree un gráfico profundo (*drill down*) de torta/barras dinámico y
  flexible

- [`Plot.Histograma()`](https://estadisticaun.github.io/UnalR/reference/Plot.Histograma.md)
  : Cree un histograma que represente gráficamente la distribución de
  datos en un conjunto, facilitando la comprensión de su frecuencia y
  patrones con dos diferentes paquetes.

- [`Plot.Mapa()`](https://estadisticaun.github.io/UnalR/reference/Plot.Mapa.md)
  :

  Cree un widget para visualizar datos geográficos en un mapa
  interactivo usando el paquete `Leaflet`

- [`Plot.Mundo()`](https://estadisticaun.github.io/UnalR/reference/Plot.Mundo.md)
  : Cree un mapa dinámico y flexible para visualizar datos geográficos
  de países

- [`Plot.Radar()`](https://estadisticaun.github.io/UnalR/reference/Plot.Radar.md)
  : Cree un gráfico de radar dinámico y flexible con dos diferentes
  paquetes

- [`Plot.Series()`](https://estadisticaun.github.io/UnalR/reference/Plot.Series.md)
  : Cree una serie de tiempo dinámica/estática y flexible con tres
  diferentes paquetes

- [`Plot.Torta()`](https://estadisticaun.github.io/UnalR/reference/Plot.Torta.md)
  : Cree un gráfico circular/torta/pie dinámico/estático y flexible con
  dos diferentes paquetes

- [`Plot.Treemap()`](https://estadisticaun.github.io/UnalR/reference/Plot.Treemap.md)
  :

  Cree un diagrama de árbol (*treemap*) dinámico y flexible con diversos
  paquetes

## Auxiliares

- [`Agregar()`](https://estadisticaun.github.io/UnalR/reference/Agregar.md)
  : Cree el consolidado a partir de los microdatos con los que dispone,
  agrupando por las variables temporales que considere necesarias

- [`StaticPlot()`](https://estadisticaun.github.io/UnalR/reference/StaticPlot.md)
  : Guarde y presente un widget HTML renderizado como una imagen
  estática

- [`read_example()`](https://estadisticaun.github.io/UnalR/reference/read_example.md)
  :

  Obtenga la ruta de los archivos de Excel para la función
  [`Agregar()`](https://estadisticaun.github.io/UnalR/reference/Agregar.md)
